🍽️ Deja Vu BBQ & Grill — GitHub Repository Description
📌 About

A modern, fully responsive restaurant website template built for Deja Vu BBQ & Grill.
This project showcases a clean and professional UI designed for restaurants, cafés, and food businesses. It is optimized for mobile, tablet, and desktop devices and can be easily customized for real clients.

🚀 Features
Fully responsive modern design
High-quality food image sections
Sticky navigation bar
Hero landing section with call-to-action
Menu showcase with cards layout
Gallery section for branding visuals
WhatsApp & Call integration for customer orders
Fast loading & lightweight code
🎯 Purpose

This project is created as a portfolio/demo website to demonstrate web design skills and can be used as a base template for real restaurant clients.
